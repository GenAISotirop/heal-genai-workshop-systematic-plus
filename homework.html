Βήμα-βήμα στο σπίτι

Κάνε τα με τη σειρά. Κάθε εργασία χτίζει στην προηγούμενη. Χρησιμοποίησε τα templates που σου δώσαμε.

1
~45 ΛΕΠΤΑ

Τρέξε τις αναζητήσεις

Μετάφρασε το ERIC search string σε PsycINFO και Scopus σύνταξη (βλ. Reference Card). Τρέξε και στις 3 βάσεις.

  • Τρέξε στο ERIC — σημείωσε αποτελέσματα
  • Μετάφρασε σε PsycINFO σύνταξη — τρέξε
  • Μετάφρασε σε Scopus σύνταξη (TITLE-ABS-KEY) — τρέξε
  • Καταγράψε στο Search Log Template (Excel)
💡
Αν τα αποτελέσματα είναι >5000 ή <50
Χρησιμοποίησε Prompt #4 (Search String Debugging) για να εντοπίσεις το πρόβλημα. Αυτή ΕΙΝΑΙ αποδεκτή χρήση ΤΝ.
2
~20 ΛΕΠΤΑ

Εξαγωγή RIS files

Από κάθε βάση, εξάγω τα αποτελέσματα σε RIS format (ή BibTeX). Αυτά θα τα ανεβάσεις στο Rayyan.

  • ERIC: Select All → Export → RIS
  • PsycINFO: Select All → Export → RIS/BibTeX
  • Scopus: Select All → Export → RIS
  • Σώσε τα 3 αρχεία σε φάκελο «homework»
3
~30 ΛΕΠΤΑ

Upload στο Rayyan

Δημιούργησε νέο project στο Rayyan και ανέβασε τα 3 RIS files.

  • Rayyan → New Review → Όνομα: «[Θέμα σου] — Workshop»
  • Upload τα 3 RIS files
  • Περίμενε deduplication (~5 λεπτά)
  • Σημείωσε: Πόσα συνολικά; Πόσα duplicates αφαιρέθηκαν;
⚠
ΜΗΝ ξεκινήσεις screening ακόμα!
Θα κάνουμε screening μαζί στο Μάθημα 2. Απλά ανέβασε τα αρχεία.
4
~45 ΛΕΠΤΑ

DOI Verification (10 papers)

Από τα Consensus αποτελέσματα του Μαθήματος 1, επαλήθευσε 10 DOIs.

  • Άνοιξε το DOI Verification Template (Excel)
  • Για κάθε DOI: πήγαινε στο doi.org/[DOI]
  • Έλεγξε: URL ανοίγει; Τίτλος ταιριάζει; Συγγραφείς ταιριάζουν;
  • Σημείωσε Yes/No στο template
  • Αν κάποιο DOI δεν επαληθεύεται → ΔΕΝ ΤΟ ΧΡΗΣΙΜΟΠΟΙΕΙΣ
5
~15 ΛΕΠΤΑ

Αυτοαξιολόγηση

Πριν έρθεις στο Μάθημα 2, βεβαιώσου:

  • Search Log συμπληρωμένο (3 βάσεις × αποτελέσματα)
  • 3 RIS files ανεβασμένα στο Rayyan
  • DOI Verification 10 papers checked
  • Αποτελέσματα σε λογική κλίμακα (200-1500)
  • Αν ΟΧΙ → έτρεξα debugging με Prompt #4

Έτοιμος για το Μάθημα 2;

Φέρε μαζί σου: laptop + login Rayyan + Search Log + DOI Verification Template. Θα δουλέψουμε πάνω στα δικά σου δεδομένα.
