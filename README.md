# 📚 Από το Prompt στη Δήλωση — SR+ Edition

> **Πλήρες εργαστήριο συστηματικής ανασκόπησης με υπεύθυνη χρήση GenAI**
> 2 × 3 ώρες + Pre-work + Homework · HEAL-Link compliant

---

## 📖 Τι είναι

Εργαστήριο 2 τριώρων που οδηγεί μεταπτυχιακούς φοιτητές από το πρώτο prompt μέχρι τη συμπληρωμένη Δήλωση Χρήσης ΤΝ — με πραγματικά δεδομένα, σύμφωνα με τις κατευθυντήριες **HEAL-Link / ΣΕΑΒ**.

### Δομή
| Φάση | Διάρκεια | Περιεχόμενο |
|---|---|---|
| Pre-work | ~2 ώρες | Tech setup, PICO primer, draft PICO, AI Agreement |
| Μάθημα 1 | 3 ώρες | Ηθική, Prompting, PICO, Search strategy |
| Homework | ~3 ώρες | Αναζητήσεις σε 3 βάσεις, Rayyan upload, DOI verification |
| Μάθημα 2 | 3 ώρες | Screening, Critical reading, Synthesis, HEAL-Link Statement |
