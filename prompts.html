8 prompts για αμέσως

Άλλαξε μόνο τα [σε αγκύλες] με τα δικά σου στοιχεία. ΜΗΝ αλλάξεις τα ΜΗΝ/ΧΩΡΙΣ — αυτοί είναι οι HEAL-Link περιορισμοί.

Prompt 1 · HEAL-Link ✓

Literature Scoping

Πότε: Αρχή έρευνας — τι ερευνητικά ρεύματα υπάρχουν στο θέμα σου

Ενεργείς ως ειδικός στην εκπαιδευτική έρευνα. Είμαι μεταπτυχιακή/ός φοιτήτρια/ής στην ειδική αγωγή. Θέμα ενδιαφέροντος: [ΘΕΜΑ ΣΟΥ] Χαρτογράφησε τα κύρια ερευνητικά ρεύματα των τελευταίων 5 ετών. Δείξε: - 3-4 κύρια θεματικά ρεύματα - Κύριες μεθοδολογίες ανά ρεύμα - 5 επιδραστικά papers (με DOI) ΜΗΝ συνθέσεις τα ευρήματα. ΜΗΝ προτείνεις συμπεράσματα. Απλώς περίγραψε τι υπάρχει. Θα ελέγξω κάθε DOI.

Αποδεκτή χρήση HEAL-Link: Scoping / χαρτογράφηση πεδίου — με DOI verification.

Prompt 2 · HEAL-Link ✓

PICO Brainstorming

Πότε: Βοήθεια διατύπωσης ερωτήματος — ΟΧΙ για να σου γράψει το PICO

Ενεργείς ως μέντορας ερευνητικής μεθοδολογίας. Έχω αυτό το αρχικό ερευνητικό ενδιαφέρον: [ΠΕΡΙΓΡΑΦΕ ΤΟ ΘΕΜΑ ΣΟΥ ΣΕ 2-3 ΠΡΟΤΑΣΕΙΣ] Βοήθησέ με να σκεφτώ τα στοιχεία PICO: - Ποια P (population) θα ήταν πιο εστιασμένη; - Τι I (intervention) είναι μετρήσιμο; - Ποια O (outcomes) έχουν καταγραφεί στη βιβλιογραφία; ΜΗΝ μου γράψεις το PICO. Κάνε μου ερωτήσεις για να το σκεφτώ μόνος/η μου.

Αποδεκτή χρήση: Υποστήριξη σκέψης, όχι υποκατάσταση ερευνητικής κρίσης.

Prompt 3 · HEAL-Link ✓

Synonym Brainstorming

Πότε: Block-by-block worksheet — Βήμα 4 (μετά τα δικά σου συνώνυμα)

Δουλεύω σε στρατηγική αναζήτησης. Έχω ήδη σκεφτεί τα παρακάτω συνώνυμα για το concept "[ΟΝΟΜΑ BLOCK]": [ΛΙΣΤΑ ΣΥΝΩΝΥΜΩΝ ΠΟΥ ΗΔΗΣ ΕΧΕΙΣ] Πρότεινε 5 ακόμα synonyms που μπορεί να μου διαφεύγουν — ιδιαίτερα όρους από MeSH, ICD, DSM ή διεθνή βιβλιογραφία. ΜΗΝ φτιάξεις το search string. ΜΗΝ δώσεις Boolean συντακτικές δομές. Μόνο επιπλέον λέξεις-κλειδιά.

Αποδεκτή χρήση: Brainstorming συνωνύμων — μετά τη δική σου λίστα. Πρώτα ΕΣΥΣ, μετά η ΤΝ.

Prompt 4 · HEAL-Link ✓

Search String Debugging

Πότε: Τα αποτελέσματα είναι πολύ πολλά ή πολύ λίγα

Ενεργείς ως ειδικός βιβλιοθηκάριος πληροφόρησης. Τρέχω αυτό το search string στο ERIC: [ΕΠΙΚΟΛΛΑ ΤΟ STRING ΣΟΥ] Αποτελέσματα: [ΑΡΙΘΜΟΣ] (ιδανικό: 200-1500) Εντόπισε πιθανά προβλήματα σύνταξης ή λογικής. Εξήγησε γιατί μπορεί να παίρνω [πολλά/λίγα] αποτελέσματα. ΜΗΝ ξαναγράψεις το string. Εξήγησέ μου τι να αλλάξω — θα το κάνω εγώ.

Αποδεκτή χρήση: Debug — ο φοιτητής εφαρμόζει τη λύση, η ΤΝ εξηγεί.

Prompt 5 · HEAL-Link ✓

Abstract Explanation

Πότε: Δυσνόητη ορολογία σε abstract κατά το screening

Εξήγησέ μου απλά τι σημαίνει "[ΤΕΧΝΙΚΟΣ ΟΡΟΣ]" στο πλαίσιο [ΠΕΔΙΟ ΣΟΥ]. Δώσε: 1. Σύντομο ορισμό (2-3 προτάσεις) 2. Ένα παράδειγμα από έρευνα 3. Γιατί είναι σχετικό με [ΘΕΜΑ ΣΟΥ] ΜΗΝ εξηγήσεις αν η μελέτη αξίζει να συμπεριληφθεί — αυτή είναι δική μου απόφαση.

Αποδεκτή χρήση: Κατανόηση ορολογίας — όχι απόφαση INCLUDE/EXCLUDE.

Prompt 6 · HEAL-Link ✓

Consensus Search

Πότε: Scoping / εύρεση papers μέσω Claude + Consensus connector

Ψάξε στο Consensus για peer-reviewed papers σχετικά με: [ΘΕΜΑ ΣΟΥ ΣΕ ΑΓΓΛΙΚΑ] Για κάθε paper που βρίσκεις, δώσε: - Τίτλο - Συγγραφείς + έτος - Κύριο εύρημα (1 πρόταση) - DOI Μόνο empirical studies. Μόνο peer-reviewed. Δεν χρειάζομαι τη δική σου ερμηνεία — μόνο τα στοιχεία. [ΣΗΜΕΙΩΣΗ: Θα ελέγξω κάθε DOI πριν το χρησιμοποιήσω]

Αποδεκτή χρήση: Εύρεση βιβλιογραφίας — με υποχρεωτικό DOI verification.

Prompt 7 · HEAL-Link ✓

Language Editing

Πότε: Γλωσσική επιμέλεια δικού σου κειμένου — αποδεκτή χρήση HEAL-Link

Ενεργείς ως γλωσσικός επιμελητής ακαδημαϊκών κειμένων. Το παρακάτω κείμενο είναι δικό μου (το έγραψα εγώ): [ΕΠΙΚΟΛΛΑ ΤΟ ΚΕΙΜΕΝΟ ΣΟΥ] Επιμελήσου το γλωσσικά: - Διόρθωσε γραμματικά λάθη - Βελτίωσε ροή και συνοχή - Βεβαιώσου ότι το ακαδημαϊκό ύφος είναι κατάλληλο ΜΗΝ αλλάξεις τα επιχειρήματα, τα ευρήματα, ή τα συμπεράσματα. ΜΗΝ προσθέσεις νέο περιεχόμενο. Επέστρεψε ΜΟΝΟ το διορθωμένο κείμενο.

Αποδεκτή χρήση HEAL-Link: Γλωσσική επιμέλεια χωρίς αλλαγή νοήματος — δηλώνεται στο Statement.

Prompt 8 · HEAL-Link ✓

Methodology Section

Πότε: Βοήθεια με τη δομή της μεθοδολογικής παραγράφου

Ενεργείς ως ειδικός σε μεθοδολογία συστηματικής ανασκόπησης. Έχω κάνει τα παρακάτω στην έρευνά μου: - PICO: [ΤΟ PICO ΣΟΥ] - Βάσεις αναζήτησης: [ERIC, PsycINFO, Scopus] - Φίλτρα: [ΕΤΟΣ, ΓΛΩΣΣΑ, κλπ] - Αποτελέσματα: [ΑΡΙΘΜΟΣ] papers - Χρησιμοποίησα ΤΝ για: [DESCRIBE] Εξήγησέ μου πώς να δομήσω τη μεθοδολογική μου παράγραφο. Δώσε μου τα στοιχεία που πρέπει να συμπεριλάβω — θα την γράψω εγώ. ΜΗΝ γράψεις την παράγραφο για μένα.

Αποδεκτή χρήση: Βοήθεια δόμησης — ο φοιτητής γράφει ο ίδιος.
